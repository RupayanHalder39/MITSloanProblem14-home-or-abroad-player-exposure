## Provenance

| File | Format | Dimensions | Bytes | SHA-256 (first 12) |
|---|---|---|---|---|

The files were received in the research workspace's `assets/` directory as
`RupayanHalder.JPG` and `SoccerSolverLogo.PNG` and copied here. The portrait is
stored under the `.jpeg` extension, which is the same JPEG format as `.jpg`;
the logo keeps its original name. Both copies were verified byte-identical to
the supplied originals, and the full digests are pinned in
`../scripts/validate_public_package.py`.

`validate_public_package.py` verifies the digest, the dimensions and the file
header of both assets on every run, and fails if either changes. Any other image
appearing anywhere in the tree is also a failure, so no unapproved picture can
be introduced.

  in this repository.

  is not an author, funder or owner, none of which is claimed. The mark is used
  for identification only; its inclusion implies no endorsement, and SoccerSolver
  contributed no data to any result published here.
